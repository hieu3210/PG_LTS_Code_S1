# Third-party components

The original PG-LTS/pyLTS license and vendored NOTICE are retained. Reused signal extraction, semantizers and descriptor modules derive from the user-supplied PG_LTS_Reproduction.zip. The sparse-group fitting path is modified; revision modules and tests implement the reviewer workflow.

`docs/IEEEtran.cls`: upstream IEEEtran v1.8b, retrieved from https://mirrors.ctan.org/macros/latex/contrib/IEEEtran/IEEEtran.cls ; license and attribution are retained in the file header.

`docs/fonts/texgyretermes-*.otf`: TeX Gyre Termes, distributed from CTAN (https://ctan.math.illinois.edu/fonts/tex-gyre/opentype/). The GUST Font License is included under docs/fonts/GUST-FONT-LICENSE.txt. The guide uses these fonts when Times New Roman is unavailable.

ROCKET/MultiRocket are provided by installed aeon 1.5.0 rather than copied or rebranded implementations. Official transform API references: https://www.aeon-toolkit.org/en/stable/api_reference/auto_generated/aeon.transformations.collection.convolution_based.Rocket.html and the corresponding MultiRocket page.
